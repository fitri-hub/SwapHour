\# Authentication Flow



\## Login

1\. User membuka halaman login

2\. User memasukkan email dan password

3\. Backend memvalidasi kredensial

4\. JWT token dibuat

5\. User diarahkan ke dashboard



\## Register

1\. User mengisi data registrasi

2\. Backend menyimpan data pengguna

3\. Akun berhasil dibuat

4\. User dapat login ke sistem
